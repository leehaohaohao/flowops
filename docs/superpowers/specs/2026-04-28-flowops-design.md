# FlowOps 设计文档

## 概述

轻量级自动化 CI/CD 部署平台，用于简化应用在 Linux 服务器上的部署流程。

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Spring Boot 3 + Thymeleaf |
| 权限认证 | Sa-Token |
| 数据库 | MySQL |
| 容器操作 | Docker Java SDK + docker-compose |
| 实时日志 | WebSocket |
| 前端 | Bootstrap + 原生 HTML/JS |

## 核心功能

### 1. 用户管理
- 管理员手动创建用户
- 支持多用户 + 角色（管理员/普通用户）
- Sa-Token 实现认证授权

### 2. 服务管理
- 创建/编辑/删除服务
- 服务配置：名称、暴露端口、挂载目录
- Dockerfile 配置（Web 端编辑预览）

### 3. 产物管理
- 上传 JAR 包（必须）
- 上传 dist 目录（如需前端）
- 产物存储在服务器本地目录

### 4. 部署执行
- 一键部署/重新部署
- 流程：停止旧容器 → 复制文件 → 启动新容器
- 手动确认机制避免误操作

### 5. 日志查看
- 实时日志 WebSocket 推送
- 历史日志列表
- 日志文件下载到本地

## 部署流程

```
1. 创建服务
   - 服务名称
   - 暴露端口
   - 挂载目录
   - Dockerfile 配置

2. 首次部署
   - 上传 JAR（必须）
   - 上传 dist（如需前端）

3. 日常部署
   - 上传新 JAR
   - 点击"重新部署"
   - 平台自动完成部署
```

## 数据库表设计

### 用户表 (sys_user)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| username | VARCHAR(50) | 用户名 |
| password | VARCHAR(100) | 密码 |
| role | VARCHAR(20) | 角色 |
| create_time | DATETIME | 创建时间 |

### 服务表 (deploy_service)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| name | VARCHAR(100) | 服务名称 |
| port | INT | 暴露端口 |
| volume_dir | VARCHAR(255) | 挂载目录 |
| dockerfile | TEXT | Dockerfile 内容 |
| status | VARCHAR(20) | 状态 |
| create_time | DATETIME | 创建时间 |

### 部署记录表 (deploy_record)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| service_id | BIGINT | 服务 ID |
| status | VARCHAR(20) | 状态 |
| log_path | VARCHAR(255) | 日志路径 |
| create_time | DATETIME | 部署时间 |

## 产物存储结构

```
/data/flowops/
├── services/
│   ├── {service-name}/
│   │   ├── app.jar
│   │   ├── dist/
│   │   └── docker-compose.yml
```

## 安全考虑

- 用户密码加密存储
- 管理员才能管理服务和用户
- 部署操作需要手动确认
- 日志文件隔离访问
